## 📌 Project Purpose

**English জানালা** is a vocabulary learning web application designed to help users improve their English skills through structured lessons and word-level details. The app includes login functionality, level-based vocabulary, pronunciation features, and an FAQ section — all built using only HTML, Tailwind CSS, DaisyUI, and Vanilla JavaScript. It integrates external APIs and offers a smooth user experience with responsive design and clean UI.

---

## 🚀 Key Features


- 🔐 **Login System** with name and password check (`123456`)
- 🧠 **Vocabulary by Levels** using external API
- 🗂️ **Word Cards** with word, meaning, pronunciation, and icons
- 🔍 **Word Details Modal** with synonyms, example sentence, etc.
- 🔊 **Voice Pronunciation** feature using `SpeechSynthesisUtterance`
- 🎨 **Responsive UI** using Tailwind CSS and DaisyUI
- 🔁 **Logout Functionality** that resets the view
- ⏳ **Loading Spinner** while fetching vocabulary
- 🍬 **SweetAlert2** for styled alerts and success messages
- 🧵 **Bangla Font Integration** for displaying Bengali words

---


## 🧩 Tech Stack & NPM Packages


- `HTML5` — Markup structure  
- `Tailwind CSS` (v4.1.x) — Utility-first CSS for layout and responsiveness  
- `DaisyUI` — Pre-built Tailwind components  
- `Vanilla JavaScript` — DOM manipulation, API integration  
- `SweetAlert2` — Beautiful custom alerts  
- `SpeechSynthesis` API — Word pronunciation
